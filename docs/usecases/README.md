# Use Cases - BDD Style User Stories

This directory contains split, fine-grained use cases derived from the original ArcheryClock (Pascal/Lazarus) codebase in `orginal-src/` and `orginal-exe/`. Each use case is written in BDD/Gherkin style (User Story + Acceptance Criteria) to be directly usable for code generation.

**References:**
- World Archery Rulebook: https://www.worldarchery.sport/rulebook
- World Archery Rules/Regulations: https://extranet.worldarchery.sport/documents/index.php/Rules/
- Original project: http://www.archeryclock.com/ (referenced in source)
- Source: `orginal-src/Countdown.pas` (extensive), `orginal-src/settings`, `orginal-exe/settings`, `orginal-exe/scenarios/gen`

**Tech target:** Rust + SDL2 (cross-platform Windows/Linux/macOS), ffmpeg for streaming option.
